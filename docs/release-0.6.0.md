# 0.6.0 版本与验证说明

本版在本地内部试用后整理为正式版。沿用 MyFlicker 安装、桥接、配对和连接向导，不需要 DSH 客户端。

## 已适配

- 自动建立任务会话，普通 use_figma 不再需要先调用 create_session；后续复用返回 sessionId。
- 批量字体解析、缓存可用字体和明确回退；内置 27 个 Feather 图标与错误预检，修正常见 strokeDashes 和可证明的同步节点读取。
- 有边界的语义上下文、变量依赖/别名、多页资源搜索、递归动效读取与有限 CSS 候选转换。
- 操作状态和保留结果、结构化错误、完整性恢复与精简恢复清单；不完整读取不解除未知写入保护。
- 可选只读脚本解释器、写入日志、重复请求去重、显式失败创建清理和检查点任务。普通任务不强制增加这些步骤。
- 限定批量编辑、变量创建与模式配额诊断；恢复属于尽力核查，不是事务或自动撤销。
- 文件级参考绑定、结构快照对比、工作区组件/token/SVG 索引与映射、惰性脚本配方。
- 原生 FigJam 图表、基本 Slides 布局、已有 Shader 发现/应用、明确提供的 DOM 快照导入。实际权限和 API 仍取决于编辑器。

## 保留的规则

保留当前页或显式 pageId，不恢复全页组件预加载。二次使用复用连接。默认创建和验收不截图、不自动导出；布局验证只返回目标及最多 19 个直接子节点的结构。回读轨道不代表播放通过，预览与导出由用户在 Figma 中完成。

暂不开放上游像素 compare、浏览器 capture_webpage、新 export_video 路由或上游 DSH 安装/UI。这些涉及额外 UI、浏览器依赖或导出工作流，未混入本次发行包。旧 export_animation 仅保留兼容，不进入自动流程。

## 安装

推荐在 MyFlicker 刷新 Marketplace 并更新 Myflicker-to-Figma；首次使用见 [安装指南](install.md)。离线本地安装也可使用发行包：

1. 在 MyFlicker 设置中安装本地 Plugin，选择解压后的整个 `Myflicker-to-Figma-0.6.0` 文件夹。
2. 新建本地 Code 会话，使用目标 Figma 文件。跟随连接向导准备配套文件。
3. 关闭并重新运行 Figma 中的插件；本版配套为 MyFlicker 协议 8，旧版会提示更新。必要时按向导重新准备并导入 manifest。
4. 发行包不自动安装到本机，测试脚本不操作真实 Figma 文件。
