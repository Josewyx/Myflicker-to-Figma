第一步：把插件导入 Figma

只需首次导入。请使用本页提供的文件，不要在安装 ZIP 中随便选择一个 manifest。

1
打开 Figma 桌面端，进入一个设计文件

第一次建议新建一个空白文件。停留在首页时，部分开发插件菜单可能不可用。

2
在 Figma 菜单中选择“从 manifest 导入”Plugins → Development → Import plugin from manifest…
插件 → 开发 → 从 manifest 导入插件
3
左侧点“下载”，打开下面这个文件夹下载 → Myflicker-to-Figma（本机专用） → manifest.json

选中 manifest.json，点击“打开”，就完成导入。不需要复制路径。

也可以把 Finder 中选中的 manifest.json 直接拖进 Figma 的文件选择窗口，再点“打开”。不要拖到设计画布上。

这是为当前电脑准备好的完整插件文件夹。请不要选安装 ZIP 中的其他文件，也不要单独移动 manifest.json。

第二步：在设计文件中运行插件

导入完成后，还需要在要操作的文件里运行它。每个文件都要单独运行一次。

Plugins → Development → Myflicker-to-Figma

运行后保持插件窗口打开；可以点击“收起”，不要关闭。此页面会自动检查，不需要刷新。

Figma 显示“An error occurred while loading the plugin environment”？

这表示 Figma 未能加载配套插件，和“等待连接”不是同一个状态。请点击红色提示里的 Show/Hide console，截图其中第一条红色错误及后面的详情，再反馈给维护者。只有通用提示无法判断具体原因。

请一并说明：操作系统、Figma 桌面端版本，以及下方诊断信息。不要发送生成的 code.js、ui.html 或整个配对目录，它们可能包含连接凭证。

查看 MyFlicker 安装入口

设置 → Plugins → 安装本地 Plugin，选择解压后的整个 Myflicker-to-Figma 文件夹。本页能打开，说明本地插件已加载。

找不到导入文件 / 安装后仍未连接

正常导入只需在文件选择框左侧点“下载”，不用找隐藏目录。找不到时，可点“在 Finder 显示导入文件”，把选中的 manifest.json 拖到 Figma 文件选择窗口内，再点“打开”。

高级排查路径：正在准备…

仅在需要时，在 Figma 文件选择框按 ⌘⇧G 后粘贴路径；不是在 Finder 空白处粘贴。

Figma 窗口中出现插件名字，只代表已导入；还需要在目标设计文件中运行。插件窗口关闭后，重新运行即可。如连接中断，先让 AI 检查实际画布再继续，避免重复创建图层。

同时连接多个文件时，请回到 MyFlicker 明确要操作的目标。安装完成后可以删除原始解压文件夹，不要删除实际安装目录。
